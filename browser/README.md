# Vydrop browser companion

Optional Chrome/Edge and Firefox companions are included in the app ZIP under `Browser`. Normal app downloads need no extension. Version 1.3.0 uses the Vydrop name and red download logo, and retains a small **Download by Vydrop** tab just above the playing video's top-right corner, outside its border, across websites including embedded HTML5 players. Clicking it copies that video's link and opens the app. You review the result, choose quality and click Download in Vydrop.

**New to the extension? Follow the illustrated [Chrome](https://github.com/ZiadHassanein/ViFree/blob/main/docs/browser-extension-setup.md#chrome), [Edge](https://github.com/ZiadHassanein/ViFree/blob/main/docs/browser-extension-setup.md#edge) or [Firefox](https://github.com/ZiadHassanein/ViFree/blob/main/docs/browser-extension-setup.md#firefox) guide**, with English and Arabic instructions. This source build packages **Vydrop 1.3.0** for the regular Vydrop app. The currently published ViFree 4.1.0 package contains **ViFree 1.2.1** and uses the same folder paths with the older name. A separately built **Vydrop Preview** companion uses the preview channel.

1. Extract the app ZIP into a permanent folder and open `Vydrop.exe` (`ViFree.exe` for the published 4.1.0 package).
2. Choose **Settings → Browser integration → Enable connection** in the app. This registers the connection for your Windows account only.
3. Chrome/Edge: open the extensions page, enable Developer mode, choose **Load unpacked**, and select `Browser/chromium`. Firefox: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `Browser/firefox/manifest.json`.
4. Play a video and click its **Download by Vydrop** tab. The tab stays visible during playback, follows the largest visible playing video within each frame, and hides when playback stops. It prefers the space above the top-right corner; version 1.2.1 also uses clear space immediately to the right when a header or caption blocks the upper position. Both placements stay outside the picture. If neither position is free, use the toolbar popup. Feedback stays outside the picture; when space is tight, the tab label and tooltip give the result. The toolbar popup and right-click link actions remain available. Finish/cancel any active download before sending another link.

For a companion-only update, extract it into a permanent folder. Chrome/Edge: open the extensions page and reload the existing unpacked companion if its folder was updated in place. If you extracted elsewhere, remove the old companion and load the new `chromium` folder. Keep that folder after installation. Accept the requested website access to show the video button, then reload open video pages. The preview companion connects to the preview app without replacing the accepted app. If the app moved, open its Settings and enable Browser integration again.

Use **Disable connection** and remove the extension to disconnect. Firefox temporary add-ons disappear when Firefox closes. These local-loading packages are not published to browser stores.

Permissions: `activeTab`, `scripting`, `contextMenus`, `nativeMessaging`, `clipboardWrite`. Content scripts run in HTTP(S) pages and embedded frames to locate visible playing video elements and position the button. Only a real user click resolves the link, writes the clipboard and sends it to the local app. There is no cookie access, clipboard reading, account import, analytics or automatic downloading. Detection reads player visibility and nearby public video identifiers/links, not login fields or private app state. Blob playback addresses are never sent as download links.

Facebook, TikTok and YouTube use the selected player's public permalink. Facebook timestamps may be warmed through pointer-entry events to reveal their public links, without navigation. Other players use their direct HTTP(S) media URL, a wrapping permalink, or the page URL when there is only one player. Ambiguous feed players produce guidance instead of sending an arbitrary homepage. Hidden/preloaded players are excluded; TikTok's visible canvas-backed player is supported. Open the specific video or use **Share → Copy link** when detection cannot determine it.

The app validates messages and limits the pipe to the current Windows user. Same-user programs are not an exclusive trust boundary. Website-wide placement does not guarantee every video can be downloaded: DRM, restricted media, closed shadow-root/custom players, browser internal pages, native video fullscreen and picture-in-picture can prevent detection or placement. The app's supported sites still determine download support. A separately built preview companion connects only to the preview app.

Vydrop retains the existing Chromium public key, Firefox add-on IDs and native-host names for compatibility. Website access and behavior are unchanged. To update an already-loaded unpacked companion, reload it once in the browser, then refresh video pages so the new name, red logo and colors appear.
