# ViFree

A free Windows video downloader by **Ziad Hassanein**. Save YouTube videos, Shorts and playlists as MP4, or choose MP3 (192/320 kbps), M4A, Opus, WAV or FLAC. Includes a download queue, playlist selection, subtitles, English/Arabic, and light/dark themes. Other public sites depend on yt-dlp support and access.

**[Download ViFree v4.0.0 for Windows (.zip)](https://github.com/ZiadHassanein/ViFree-Downloads/releases/download/v4.0.0/ViFree-v4.0.0-win-x64.zip)**

Windows 10/11 x64. Extract the ZIP and open **ViFree.exe**. The runtime is bundled; missing media tools are prepared automatically. The optional browser companion is inside `Browser` in the same ZIP.

Earlier v3.0.2 interface; v4 adds Output options and Queue. Click a screenshot for full size.

1. Paste a video or playlist link.
2. Choose the output, quality and save folder. Use **Output options** for audio formats/subtitles, **Choose videos** for playlist selection, or **Queue** for multiple links.
3. Click **Download**.

**Upgrading from v3.x or a preview:** close the old app and download this ZIP once. Stable settings, history and downloaded files are retained; preview preferences stay separate. Future v4 updates are manual through **Check for updates**.

Only save content you have permission to download. Protected and sign-in-only media is unsupported.

## العربية

حمّل ملف ZIP وافتح **ViFree.exe**. الصق الرابط واختر الصيغة والجودة ومجلد الحفظ، ثم اضغط **تنزيل**. يدعم التطبيق طابور التنزيلات، اختيار فيديوهات قائمة التشغيل، والترجمة وصيغ الصوت MP3 وM4A وOpus وWAV وFLAC. تُجهّز الأدوات الناقصة تلقائيًا. إضافة المتصفح اختيارية ومرفقة داخل مجلد **Browser** في نفس الملف. للترقية من v3 أو نسخة تجريبية، أغلق التطبيق القديم وحمّل الملف الجديد مرة واحدة.
