# كيف أحفظ صوت يوتيوب بصيغة MP3 على ويندوز؟

الصق رابط فيديو يوتيوب عام ومدعوم في Vydrop واختر **صوت ← MP3**. يحوّل التطبيق الصوت المتاح محليًا دون حساب أو مفتاح API أو اشتراك.

1. انتظر معلومات الفيديو ثم اختر الصوت وMP3.
2. اختر تلقائية أو إحدى جودات الصوت المعروضة؛ تعتمد خيارات معدل البت على تقدير المصدر وصيغة الإخراج.
3. حدّد مجلد الحفظ واضغط تنزيل.

## اختيار جودة واقعية

عند عدم معرفة جودة المصدر يتاح الاختيار التلقائي. لا يستعيد رفع معدل البت تفاصيل فقدها الصوت المضغوط. تتاح WAV وFLAC كصيغ إخراج دون فقد إضافي، لكنها لا تجعل المصدر المضغوط تسجيلًا أصليًا بلا فقد. تتاح أيضًا M4A وOpus.

لتنزيل عدة فيديوهات استخدم [اختيار عناصر القائمة](download-youtube-playlist-windows.md) أو قائمة التنزيلات. تنطبق الخطوات أيضًا على [المواقع العامة المدعومة](supported-sites.md).
