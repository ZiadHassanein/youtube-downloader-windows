# كيف أرسل فيديو تيك توك أو فيسبوك إلى Vydrop؟

يحفظ Vydrop فيديوهات تيك توك وفيسبوك العامة والمدعومة التي لا تتطلب تسجيل دخول. استخدم رابط الفيديو نفسه بدل الصفحة الرئيسية.

1. افتح الفيديو أو المقطع المحدد وشغّله.
2. بعد تفعيل الإضافة، اضغط **تنزيل بواسطة Vydrop** بجانب المشغّل؛ تحدد الإضافة الرابط العام القريب من الفيديو المختار.
3. راجع الرابط والعنوان وخيارات الإخراج في التطبيق ثم اضغط تنزيل.

إذا لم يتضح الفيديو المقصود، اختر **مشاركة ← نسخ الرابط** في الموقع والصقه يدويًا. لا ترسل ملفات تعريف ارتباط أو كلمات مرور أو بيانات حساب للدعم. مشاهدة الفيديو أثناء تسجيل الدخول لا تضمن تنزيله دون الحساب.

راجع [دليل Chrome وEdge وFirefox](browser-extension-setup.md) و[قيود المواقع](supported-sites.md). قد تحتاج تغييرات الموقع إلى تحديث من المطوّرين الأصليين، ولا نعد بإزالة العلامة المائية.
