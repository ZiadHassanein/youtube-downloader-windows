# كيف أنزّل فيديو من المواقع العامة على ويندوز؟

استخدم Vydrop لتنزيل الفيديو العام من أي موقع تدعمه yt-dlp. يدعم التطبيق مواقع متعددة، لكن لا يضمن كل موقع أو مشغّل.

1. انسخ رابط الفيديو العام نفسه. يمكن أيضًا استخدام رابط MP4 مباشر لمشغّل HTML5 عادي.
2. الصقه في Vydrop وانتظر معلومات الوسائط.
3. اختر الفيديو ثم MP4 أوMKV أوWebM؛ تظهر الجودات المتوافقة مع المصدر.
4. حدّد الجودة المتاحة ومجلد الحفظ واضغط تنزيل.

للفيديو الجاري تشغيله في Chrome أوEdge أوFirefox، اتبع [دليل الإضافة بالصور](browser-extension-setup.md). يظهر الزر خارج الحد العلوي الأيمن عندما تتوافر مساحة، ويمكن استخدام زر شريط الأدوات عند تعذّر وضعه.

## عند فشل الفحص

تأكد أن الرابط لفيديو وليس صفحة رئيسية، وأنه متاح دون تسجيل دخول وضمن [المواقع المدعومة](supported-sites.md). رابط blob محلي داخل المتصفح وليس رابط وسائط عامًا يمكن إعادة استخدامه.
