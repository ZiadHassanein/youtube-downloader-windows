# كيف أنزّل قائمة تشغيل يوتيوب على ويندوز؟

الصق رابط قائمة يوتيوب عامة في Vydrop واختر **القائمة كاملة**، ثم حدّد العناصر المطلوبة. اختر الفيديو أو الصوت قبل تنزيل العناصر المحددة بالترتيب.

1. انسخ رابط القائمة؛ قد يعرض رابط فيديو يحتوي على قائمة اختياري هذا الفيديو أو القائمة كاملة.
2. افتح اختيار الفيديوهات واترك العناصر التي تريدها.
3. اختر الصيغة والجودة المتاحة ومجلد الحفظ. للصوت تتاح MP3 وM4A وOpus وWAV وFLAC.
4. ابدأ التنزيل وراجع العناصر المكتملة أو التي فشلت داخل قائمة التنزيلات، وافتح المجلد من العنصر المكتمل.

## المزيج والعناصر غير المتاحة

يتغير مزيج الراديو في يوتيوب بمرور الوقت، لذا يفحص التطبيق عينة محدودة ولا يعد بالقائمة المتغيرة كاملة. قد لا تتاح العناصر الخاصة أو المحذوفة أو التي تتطلب تسجيل الدخول. وقد يوقف تجاوز حد الطلبات أو خطأ التوافق المستمر العمل اللاحق للمراجعة.

تُستأنف فقط المخرجات المكتملة والمتوافقة. تدخل إعدادات الترجمة ضمن هوية الإخراج. راجع [جودة الصوت](youtube-to-mp3-windows.md) و[صيغ الترجمة](youtube-subtitles-srt.md).
