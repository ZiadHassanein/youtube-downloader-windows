## English — short

Vydrop is a free, open-source Windows video and audio downloader powered by yt-dlp. Save supported public media from YouTube, TikTok, Facebook, Vimeo and 1,000+ sites. Choose video or audio formats, available quality, subtitles, playlists and a queue. English and Arabic interfaces and an optional Chrome, Edge and Firefox companion are included. No account or paid API is required.

## English — extended

Vydrop is a free, MIT-licensed desktop application for downloading video and audio on Windows 10/11 x64. Formerly ViFree and YouTube Downloader, it brings public media supported by yt-dlp into one English or Arabic interface. Supported scope includes YouTube, TikTok, Facebook, Vimeo, X/Twitter, Reddit, Dailymotion, Twitch clips and compatible direct MP4/MP3 links, subject to site access and extractor support.

The app inspects source streams before offering output choices. Video formats include MP4, MKV and WebM; audio formats include MP3, M4A, Opus, WAV and FLAC. Output quality depends on the original media. Playlists, selected entries, a download queue, progress and available SRT/VTT captions help manage multiple files.

The optional browser companion places Download by Vydrop beside a playing video when supported, copies its resolved public link and opens the app for review. Chrome, Microsoft Edge and Firefox setup guides are included; Firefox's local add-on is temporary. Missing media tools are prepared automatically, with verified update checks for yt-dlp and Deno. No account, API key or subscription is needed, and Vydrop collects no telemetry. Private, sign-in-only and DRM-protected content is unsupported. Download only media you have permission to save.
