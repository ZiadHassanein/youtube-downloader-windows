# How do I download public web videos on Windows?

Use Vydrop to download public video from any site supported by yt-dlp. It is a Windows app for many websites, with no guarantee that every website or player is supported.

1. Copy the public video's own URL. For a standard HTML5 player, a direct MP4 URL may also work.
2. Paste it into Vydrop and wait for the media details.
3. Choose **Video**, then MP4, MKV or WebM from the format menu. Only compatible inspected streams are offered.
4. Choose an available quality and save folder, then **Download**.

For a video already playing in Chrome, Edge or Firefox, follow the [illustrated companion setup](browser-extension-setup.md). Its tab sits outside the video's top-right border where space permits. Use the toolbar popup when placement is unavailable.

## If inspection fails

Check that the link is a video rather than a homepage, that it is public without sign-in, and that the site is in the [supported scope](supported-sites.md). A blob URL is local to the browser and cannot be pasted as a reusable public media link.
