# How do I save available YouTube subtitles as SRT?

Use **Subtitles** in Vydrop to save an available caption track as SRT or VTT alongside the downloaded media. The app uses the source's captions; it does not create a transcript for a video without captions.

1. Paste the public video link and wait for inspection.
2. Open **Subtitles**, enable captions, and choose an available language. Automatic captions are identified separately when available.
3. Select **SRT** or **VTT** and confirm. Check the selected caption language and format in the media details panel.
4. Download the media. Keep the subtitle sidecar with it for playback.

An unavailable language cannot be promised. A caption track may disappear between inspection and download; refresh the choices or disable subtitles if that happens. See the [playlist guide](download-youtube-playlist-windows.md) for selected entries.
