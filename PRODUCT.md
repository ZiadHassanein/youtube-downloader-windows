# Vydrop

Vydrop is a free, MIT-licensed Windows 10/11 x64 desktop video and audio downloader by Ziad Hassanein. Former names are ViFree and YouTube Downloader. The repository slug remains ViFree for installed updater compatibility.

The primary task is to paste or send a public media link, inspect actual source choices, choose output and save it locally. Users can select playlist entries, queue several links, save available captions and review completed files. English and Arabic have equal support, with light and dark themes. Fresh profiles start in English and dark mode.

Site support comes from yt-dlp, covering 1,000+ supported public sites, plus compatible direct media links. It is not a guarantee that every website, player or URL works. Private, sign-in-only and DRM content is unsupported. Higher output bitrate does not restore missing source detail. There is no paid API, account requirement, telemetry or hidden download.

The browser companion is optional. Chrome, Edge and Firefox installation is local; Firefox's unsigned local add-on is temporary. A deliberate click copies a resolved public link and opens the matching app for review. Browser accounts and cookies are not imported.
